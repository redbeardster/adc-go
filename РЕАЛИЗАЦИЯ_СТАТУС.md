## 🚀 Примеры использования

### 1. Базовый workflow
```bash
# Инициализация
adc init

# Создание конфигурации
vim my-config.yaml

# Валидация
adc validate -f my-config.yaml

# Просмотр изменений
adc diff -f my-config.yaml

# Применение (с автоматическим backup)
adc apply -f my-config.yaml
```

### 2. GitOps workflow
```bash
# В Git репозитории
git clone https://github.com/company/apisix-config.git
cd apisix-config

# Применение конфигурации
adc apply -f production.yaml

# Коммит изменений
git add production.yaml
git commit -m "Add new API route"
git push
```

### 3. Disaster recovery
```bash
# Создать backup
adc backup --description "Before major update"

# Применить изменения
adc apply -f new-config.yaml

# Если что-то пошло не так
adc backup-list
adc restore backup-20260211-183445.yaml
```

### 4. Миграция между окружениями
```bash
# Экспорт из staging
adc dump -o staging-config.yaml

# Применение в production
adc apply -f staging-config.yaml
```
